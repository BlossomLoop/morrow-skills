## 4. 演进与治理

### 4.1 宪法修订流程

1. 提案人提交修订草案（含动机、影响分析、兼容方案）
2. 架构负责人 + 业务负责人双签
3. 修订后必须同步刷新：ADR / 架构文档 / 契约 / 骨架 README
4. 版本号递增并记入 §0 修订历史

### 4.2 违规响应

- 发现违规 → 立即记入风险登记（`risk-and-evolution.md`）
- 修复优先级：违反安全/SLA 原则 > 违反架构底线 > 违反测试底线
- 若短期无法修复，必须在宪法中登记"临时豁免 + 到期日"
