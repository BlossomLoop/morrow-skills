# ADR 触发清单（Phase 9 使用）

> 基线 ADR 4 份是最低标准；下面的触发清单用于 Phase 9 判断"是否应该动态追加新的 ADR"。
> 每检出一个触发点且本期确实做了决策，就必须新增独立 ADR，不允许压缩进基线 4 份。

## 判定规则

凡符合以下**任一**条件，必须独立成一份 ADR：

1. 该决策存在 ≥ 2 条合理技术路径（即"有得选"）
2. 该决策如果将来要回退，代价超过 "改一两处代码"
3. 该决策与某条宪法原则相关（支持或克制）
4. 该决策影响 ≥ 2 个组件的行为或数据

## 基线 ADR（必须）

- ADR-001 系统边界与模块拆分
- ADR-002 技术栈选型
- ADR-003 数据与集成策略
- ADR-004 API 与安全风格

## 动态追加触发清单

按领域分类；每条的"典型题目"是给作者的灵感触发器。

### A. 数据与存储

- [ ] 数据持久化策略（完整 / 仅摘要 / 不持久化）
- [ ] 数据分片 / 分库策略
- [ ] 跨服务事务一致性策略（Saga / TCC / 2PC / 最终一致）
- [ ] 缓存策略（旁路 / 读穿透 / 写穿透 / 写回）
- [ ] 冷热数据分层
- [ ] 数据保留期与清理策略
- [ ] 向量索引方案（进程内 / 独立服务 / 云托管）

### B. 集成与异步

- [ ] 消息中间件选型（Kafka / Pulsar / RabbitMQ / Redis Pub/Sub 替代）
- [ ] 异步任务回调策略（Webhook / 轮询 / 长连接）
- [ ] 外部 API 降级策略（熔断 / 限流 / Fallback）
- [ ] 幂等键设计
- [ ] 重试与死信处理

### C. 运行时 & 演示

- [ ] 演示 / 兜底开关（demo-mode、feature-flag、kill-switch）
- [ ] 灰度发布 / 金丝雀策略
- [ ] 多环境配置管理

### D. 安全

- [ ] 鉴权模式（签名 / OAuth / JWT / 声纹等）
- [ ] 多租户隔离（共享库 + owner_id / 每租户独立库 / 独立集群）
- [ ] 敏感数据处理（脱敏 / 加密 / 访问审计）
- [ ] 内容安全与红线拦截

### E. AI / LLM 专有（如涉及）

- [ ] LLM 底座选型与多底座切换策略
- [ ] LLM 输出校验链
- [ ] RAG 检索策略
- [ ] Skill / Tool 沙箱执行

### F. 可观测性

- [ ] Trace / 指标采集方案
- [ ] 告警策略与 SLO 定义
- [ ] 日志归档与检索策略

### G. 特殊业务场景

- [ ] 状态机设计（若业务含复杂状态流转）
- [ ] 时间 / 时区处理策略
- [ ] 国际化 / 多语言策略

### H. 抽象接口完整性（防止"半抽象"）

> 这类问题的典型症状：定义了 `interface X` 但调用方仍要 `if (impl == "foo") ...`。
> 说明抽象没收口，应该独立成一份 ADR 决策"要么扩接口、要么加 adapter、要么放弃抽象"。

- [ ] H.1 抽象接口承担了 ≥ 2 种不同语义的调用（例如 LLM 的"纯补全"vs"工具调用"vs"嵌入"），但当前签名只能表达其中一种
- [ ] H.2 多个实现之间存在"各自扩展字段"的诱惑，调用方会按具体实现分支判定
- [ ] H.3 跨 ADR 出现"A 说抽象接口 / B 说具体厂商能力"但两者之间缺少 adapter / translator 衔接点
- [ ] H.4 抽象接口的错误模型不统一（某 impl 抛 checked exception，另一个返回 null / Optional），调用方无法写通用处理

**判定法则**：写一条调用方伪代码，如果出现 `if (provider instanceof Foo)` 或 `switch (type)` 来绕过接口，就是触发点。

## 使用流程（Phase 9）

1. 过一遍上面 8 大类
2. 每打钩一项，生成 `adr/ADR-00X-xxx.md`
3. 在每份 ADR 的"关联 FR/US"字段回链 Phase 1 产出的需求编号
4. 在"涉及宪法条款"字段列出 Phase 0.5 的 P-xxx
5. 如果触发项没做决策（推迟了），登记到 `risk-and-evolution.md §9 待确认项`

## 反模式（禁止）

- ❌ 把 3 个独立决策塞进 ADR-003 的"备选方案"章节
- ❌ ADR 里只写"我们选了 X"却不写"为什么不选 Y / Z"
- ❌ ADR 缺"涉及宪法条款"字段——这会让宪法形同虚设
- ❌ ADR 之间互相复制粘贴背景（应互相引用）
