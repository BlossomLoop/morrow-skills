# 历史问题汇总

> 这是历史问题的脱敏归纳，不是可复现的原始评测报告。项目、客户、供应商、设备细节、具体时间预算、评分和内部产物路径已移除；以下条目只保留可复用的问题与验证方法，不能用作当前版本通过的依据。

| 问题 | 检查方法 |
| --- | --- |
| 业务空壳 | 曾出现空方法仍锁定业务类名和依赖的情况；用产物扫描验证，不能只看模板要求。 |
| 外部假设 | 为每项外部假设记录决策人、截止条件和降级方案。 |
| 风险拆分 | 外部服务限流、现场网络和设备兼容性需要分别记录处理方式。 |
| 契约覆盖 | 核对需求到接口以及接口到需求两个方向，检查 WebSocket 上下行、错误响应、幂等和重试。 |
