# 架构方案检查经验

> 这是历史问题的脱敏归纳，不是可复现的原始评测报告。项目、客户、供应商、设备细节、具体时间预算、评分和内部产物路径已移除；以下条目只保留可复用的问题与验证方法，不能用作当前版本通过的依据。

| 问题 | 检查方法 |
| --- | --- |
| 候选方案 | 比较保留现状和新增组件两种方案，说明成本、风险及不采用的理由。 |
| 接口完整性 | 抽象接口必须能表达已承诺的调用能力；只提供一种调用模式可能不足。 |
| 外部依赖 | 未确认的契约、容量和设备行为不能直接作为架构成立的前提。 |
| 实测要求 | 线程数、延迟预算、重试次数和容量阈值需要标明假设或测量结果。 |
